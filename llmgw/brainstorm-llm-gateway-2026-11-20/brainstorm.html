01
Divergent lens / switching fabric

SCAMPER Method

Seven verbs thrown across the problem like patch cables. Each port rewires a different part of the gateway — what gets swapped, fused, borrowed, tuned, repurposed, deleted, or turned inside out.

7 PORTS
34 PATCHES
ALL CIRCUITS LIVE
S

Substitute

Swap the part, keep the job.

  • 01

    Unified OpenAI-compatible API facade so apps swap providers without code changes.

  • 02

    Hot-swap model backends — OpenAI / Anthropic / Gemini / local vLLM — via config, not deploys.

  • 03

    Replace hardcoded API keys in apps with gateway-issued virtual keys and tokens.

  • 04

    Substitute raw prompts with managed prompt templates and versioned prompt IDs.

  • 05

    Replace per-app billing with centralized cost attribution and chargeback.

C

Combine

Fuse two mechanisms into one.

  • 01

    Route + fallback + load-balance in one policy: primary model, fallback chain, weighted pools.

  • 02

    Combine streaming responses with real-time token/cost metering and SSE passthrough.

  • 03

    Bundle authn/authz, quotas, and audit logging into a single request pipeline.

  • 04

    Merge semantic cache + exact cache + prompt-prefix caching for latency and cost wins.

  • 05

    Combine RAG retrieval hooks and tool-call mediation in the gateway layer.

A

Adapt

Borrow proven machinery.

  • 01

    Adapt API-gateway patterns from Kong/Envoy — plugins, middleware, declarative routes, canaries.

  • 02

    Adapt CDN ideas — edge/regional PoPs, geo-routing to nearest provider region, response caching.

  • 03

    Adapt feature-flag systems for gradual model rollouts and A/B prompt/model experiments.

  • 04

    Borrow circuit-breaker and bulkhead patterns from microservices for provider resilience.

  • 05

    Adapt OAuth/OIDC and RBAC from IAM platforms for tenant and team-level access control.

M

Modify

Tune the shape of the request.

  • 01

    Dynamic context-window management — auto-truncate/summarize history to fit model limits.

  • 02

    Request/response transformation layer — normalize schemas, map parameters across vendors.

  • 03

    Configurable retry policies with exponential backoff, jitter, and idempotency keys.

  • 04

    Token-aware rate limiting (TPM/RPM/concurrency) per key, user, team, or tenant.

  • 05

    Response shaping — enforce JSON schema/structured output, normalize function calling.

P

Put to other use

Same gateway, new job.

  • 01

    Gateway as an evaluation harness — replay prod traffic against candidate models.

  • 02

    Use gateway logs as a fine-tuning/distillation dataset pipeline with consent and PII controls.

  • 03

    Gateway as a compliance choke point for data residency and PII redaction.

  • 04

    Expose gateway metrics to FinOps for forecasting and budget alerts.

  • 05

    Developer sandbox mode with mock models and recorded fixtures for testing.

E

Eliminate

Delete the failure mode.

  • 01

    Remove vendor lock-in by enforcing a provider-agnostic internal contract.

  • 02

    Eliminate secret sprawl by centralizing provider credentials in a secrets vault integration.

  • 03

    Strip PII and secrets from prompts and logs via configurable redaction policies.

  • 04

    Remove manual incident toil with auto-failover and health-based provider ejection.

  • 05

    Eliminate surprise bills with hard spend caps, budget thresholds, and kill switches.

R

Reverse

Flip direction or trust.

  • 01

    Invert client-pull to gateway-push callbacks/webhooks for long-running or async jobs.

  • 02

    Instead of apps choosing models, gateway auto-selects cheapest/fastest model meeting the SLO.

  • 03

    Reverse the trust boundary — treat model outputs as untrusted; validate and guardrail before returning.

  • 04

    Shift observability from app-side instrumentation to gateway-native tracing and metrics.

GUARD

LATENCY SPIKES

→

GUARD

Streaming-first responses, timeouts, hedged requests, and fast-model fallback.

COST RUNAWAY

→

GUARD

Per-request cost estimation, budget enforcement, and anomaly kill switches.

F-05

PROMPT INJECTION / EXFIL

Untrusted text tries to escape the sandbox.

→

GUARD

Input/output guardrails, tool sandboxing, and allow/deny policies.

F-06

CONTEXT OVERFLOW

History exceeds the model window.

→

GUARD

Automatic truncation, summarization, or map-reduce chunking strategies.

F-07

BAD / NON-DETERMINISTIC OUTPUT

The answer is malformed or wrong.

→

GUARD

Schema validation, self-check/repair retries, and verifier models.

F-08

KEY / SECRET LEAK

Credentials end up in code or logs.

→

GUARD

Vault-backed secrets, rotation, scoped virtual keys, and no-secret logging.

F-09

COMPLIANCE BREACH

Data crosses a boundary it shouldn't.

→

GUARD

Data residency routing, retention controls, PII redaction, and audit trails.

F-10

DEBUGGABILITY FAILURE

No one can reconstruct what happened.

→

GUARD

End-to-end tracing (OpenTelemetry), prompt/response replay, and diffing.

F-11

NOISY NEIGHBOR

One tenant starves the rest.

→

GUARD

Tenant isolation, fair scheduling, and per-tenant quotas/budgets.
