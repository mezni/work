- (decision) AD-1 Hexagonal ports-and-adapters over a DDD core; dependency direction server->adapters->application->domain, domain depends on nothing
- (decision) AD-2 Fixed ordered request pipeline: validate, authn, authz, rate/quota, input guardrail, route, resilience/provider, output guardrail, meter, audit; each stage a trait
- (decision) AD-3 Failover only before first streamed token; after first token no retry; mid-stream error terminates SSE with error event then DONE
- (decision) AD-4 Provider adapter contract normalizes request/response, capability descriptor, and error taxonomy; no provider-specific fields leak to the OpenAI surface
- (decision) AD-5 Routing policy is a pure domain function of request, principal, policy, and provider health returning an ordered target list; no I/O
- (decision) AD-6 Postgres is system of record for control plane and usage/audit events; Redis owns only ephemeral counters, circuit and health cache; no dual writes
- (decision) AD-7 Non-secret config in versioned control-plane DB; secrets only from managed secret store, runtime-resolved, cached, never logged or persisted
- (decision) AD-8 OIDC JWT or gateway-issued scoped API key; every data-plane call has principal+team+scopes; provider keys never leave gateway
- (decision) AD-9 Immutable usage event per attempt with request_id/attempt_id dedupe; cost snapshot from versioned price table at event time
- (decision) AD-10 Fixed OTel span/attribute and Prometheus metric contract in llmgw_ namespace; request_id propagated end to end
- (decision) AD-11 Stable OpenAI-compatible error envelope; gateways own error taxonomy, never leak raw provider errors
- (decision) AD-12 Control plane and data plane are separate deployments and credential scopes; data plane never calls the web app
- (decision) AD-13 Kubernetes stateless data-plane pods; managed Postgres/Redis; Vault/ESO for secrets; OTel Collector; separate control-plane deployment
- (decision) AD-14 Guardrails are provider-agnostic in-process stages; input guardrails P1, output guardrails and streaming redaction deferred
- (decision) AD-15 Attempt budget and idempotency key; no double billing; attempts recorded in usage events
- (decision) AD-16 Python SDK is thin transport + typed models, not a second router; failover lives only in gateway
- (decision) AD-17 Prompt/response bodies not persisted by default; opt-in redacted body capture only
